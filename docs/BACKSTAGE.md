# BACK STAGE — 방탈출 시리즈 메모

사용자가 매주 친구들과 푼 "Back Stage" 방탈출 문제를 1인칭 three.js 방으로 옮긴 시리즈입니다. 주차마다 방 하나가 있고, 각 방에는 자물쇠 6개와 출구가 있으며 제한 시간은 60분입니다.
엔진 사용법(테마 계약, 자물쇠·단서 형식, 디버그 API)은 [engine/README.md](../engine/README.md)에 있습니다. 이 문서는 그 밖의 맥락을 담습니다.

## 방 목록
| 폴더 | 이름 | 주차 주제 |
|---|---|---|
| `w1/` | CLASSROOM | 타임고등학교 3학년 4반 (기준 테마) |
| `w2/` | PUB | TIME PUB |
| `w3/` | DESK | 게임 기획 혹평 |
| `w4/` | MONITOR | 출간 원고의 혹평 |
| `w5/` | STAGE | 무대 (나다운 길) |
| `w6/` | TIME CASINO | 학교 쉬는 시간 내기 (가장 오래되고 큰 테마) |

- 테마 선택 화면은 `backstage.html`입니다. 방에서 나가는 링크도 여기로 연결됩니다.
- 기록은 `localStorage['bs-record-wN']`에 저장되며, 메인 메뉴에 "탈출 n / 6"으로 표시됩니다.

## 설계 원칙 (플레이테스트로 정해진 것 — 유지할 것)
- 방 안 단서는 처음부터 모두 보입니다. 어떤 단서가 어느 자물쇠의 짝인지는 알려 주지 않습니다.
- 자물쇠 n의 **연관 단서**는 자물쇠 n−1이 열려야 깨어납니다.
  - 자물쇠가 열리면 컷신이 나옵니다. 불꽃이 다음 장치로 날아가 그 단서를 깨웁니다.
  - "어디로 가라" 같은 글 안내는 하지 않습니다.
- 자물쇠는 아무 때나 시도할 수 있습니다. 찍어서 맞히는 것도 허용합니다.
- 프롤로그는 픽셀아트 장면 + 타자 효과 + 선택형 한국어 TTS입니다. 엔딩은 불꽃놀이 + 에필로그 + 기록 시간입니다.
  - 프롤로그 복선은 은근하게 둡니다. 게임이나 정답 이름을 직접 말하지 않습니다.
- 힌트는 자물쇠마다 2단계이고, 전체 사용 횟수에 제한이 있습니다. 1단계는 짝 단서, 2단계는 푸는 방법을 알려 줍니다.
- **단서 펼쳐 두기** (엔진 기능, 2026-11):
  - 📌 버튼으로 단서를 카드로 꺼내 둡니다. 걸어다닐 때도, 자물쇠를 입력할 때도 화면에 남습니다.
  - 최대 6개이고, 나란히 정렬·모두 접기·모두 치우기를 지원합니다.
  - 실제 방탈출에서 단서를 들고 다니며 옆에 두고 비교하는 경험을 옮긴 것입니다.
- 동선: 플레이어 반경은 0.24입니다. 가구 사이 통로는 막히지 않게, 겉보기 가구에는 `collide()`로 충돌 영역을 줍니다. 예전에 w1·w4·w5에서 끼임이나 통과 문제를 고쳤습니다.

## 소리·영상 단서
- 원본 음성은 AAC로 인코딩해 `.mp4`로 둡니다(아티팩트가 `.m4a`를 서빙하지 않음). STT 자막을 `captions: [[t0, t1, '텍스트'], …]`로 붙입니다.
  - "글자로 보기"를 누르면 자막을 천천히 보여 줍니다.
  - 이전에는 macOS SpeechTranscriber를 Swift 스크립트로 돌려 자막을 뽑았습니다. 다른 환경에서는 Whisper 같은 도구로 대신하면 됩니다.
- 저작권 있는 노래는 공식 유튜브 임베드만 씁니다. `cover: false`로 썸네일을 숨겨 답이 미리 보이지 않게 합니다.
  - w4 Ben 「180도」 `0T_FLL9_R4Q`
  - w3 MAMAMOO 「데칼코마니」 `u8ukVmSf2ik`: 제목이 "반쯤 지워진 END GAME 이미지를 거울처럼 뒤집으라"는 힌트입니다.
  - w4 기승전결 영상 `p8PiIKAFsSI`
- 외부 링크 단서는 `type: 'link'`에 `fallback` 텍스트를 함께 둡니다. 예: w3 규약 rentry.co/zs5syg3a.

## 새 방 / 수정 절차
1. `w1/`을 복사해 `wN/`을 만듭니다. `index.html`에서는 팔레트 토큰과 제목 폰트만 바꿉니다.
2. `theme.js`에 이야기(intro, prologue, epilogue), 단서, 자물쇠, 컷신 위치, `build(api)`를 작성합니다.
   - 정답은 `node tools/hash.mjs bs 정답 별칭…`으로 만든 해시로 넣습니다.
3. `backstage.html`에 포스터 카드를 추가하고, 메인 메뉴 `index.html`의 포스터 그리드와 `탈출 n / 6` 계산 범위도 함께 고칩니다.
4. `#debug`로 끝까지 검증합니다. 절차는 [engine/README.md의 Testing](../engine/README.md#testing)에 있습니다.
   - 모든 자물쇠 → 컷신 → 출구 → `state.finished`까지 확인합니다.
   - 휴대폰 폭(조이스틱·조사 버튼)도 확인합니다.
